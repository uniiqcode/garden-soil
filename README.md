# 土日和(つちびより)

**次の晴れの日に、畑の土にすること** を教える家庭菜園のWebアプリです。

住んでいる場所の気候(寒冷地・中間地・暖地)と天気予報から、土の作業ができる次の日を見つけ、その日にやることを出します。
くわしいやり方は、企業のホームページ・ブログ・YouTube へのリンクで案内します。

## できること

- **次の作業日**: 雨がやんで土が乾いた晴れ(または曇り)の日を探します。
  ふつうの土なら「昨日で雨が上がった → 今日は乾かす → 明日が作業日」。砂っぽい土は1日早く、粘土っぽい土は1日遅く、大雨(20mm以上)のあとはさらに1日遅くなります。
- **この先2週間の空と土**: 日ごとに ◎(晴れで作業日和)・○(曇りだが作業できる)・—(向かない)と、その理由。
- **植え付けまでの段取り**: 作物と植え付け予定日を選ぶと、pH測定 → 苦土石灰 → 堆肥・元肥 → 畝立て・マルチ を逆算し、天気の良い日に割り当てます(石灰と堆肥は7日あける)。
- **季節の土づくり**: 寒起こし・片付け・腐葉土・緑肥・太陽熱消毒・果樹の植え穴など、今月の作業と参考リンク。

## しくみ

サーバーを持たない静的サイトです(GitHub Pages で配信)。設定は見る人の端末(localStorage)にだけ保存します。

| 使うもの | 用途 |
|---|---|
| [Open-Meteo](https://open-meteo.com/) Forecast API | 過去7日+先16日の天気(APIキー不要、CC BY 4.0) |
| Open-Meteo Historical API | 過去3年の年平均気温 → 地域区分 |
| [国土地理院 住所検索](https://msearch.gsi.go.jp/) | 住所 → 緯度経度 |

位置は小数2桁(約1km)に丸めてから使います。

## ファイル

```
index.html            画面
css/style.css         見た目(空と土の色)
js/logic.js           判定ロジック(作業日・地域区分・段取り)。画面に依存しない
js/app.js             画面の組み立て・API呼び出し・保存
data/tasks.json       季節の作業と参考リンク ← リンクの追加・差し替えはここ
data/crops.json       作物と段取りのひな形
sw.js                 オフライン用(CACHE_NAME)
manifest.webmanifest  ホーム画面に追加するときの設定
icons/ favicon.*      アイコン(作り方は tools/icon/README.md)
tests/                テスト
docs/spec.md          判定ルールなどの仕様
```

## 手元で動かす・テスト

```bash
python3 -m http.server 8080      # http://localhost:8080/ を開く
npm test                         # 判定ロジックのテスト(Node 20 以上)
node tests/ui.mjs                # 画面のテスト(天気・住所検索は試験データ。サーバーを起動しておく)
```

## 参考リンクについて

`data/tasks.json` の `links` は、検索で見つけた企業サイト・YouTube のページです。
作成時の環境からはリンク先を開けなかったため、**内容は人の目で確認してから公開してください**(確認したら `checked` の日付を更新)。

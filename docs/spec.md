# 土日和 仕様

## 1. 作業日の判定(`js/logic.js` の `judgeDays`)

日ごとに次を順に見る。

1. **雨の日**: 降水量 1mm 以上、または降水確率 50% 以上、または天気が雨・雪 → 作業しない
2. **空**: 晴れ(WMOコード 0〜2)か曇り(3)でなければ作業しない(霧など)
3. **凍結**: 最高気温が0℃以下 → 作業しない
4. **乾き**: 最後の雨の日から、雨なしの日が「必要な日数」続いていること
   - 必要な日数 = 土の基本日数(砂っぽい 0 / ふつう 1 / 粘土っぽい 2)+ 最後の雨が 20mm 以上なら 1
   - 例(ふつう): 11/4 で雨が上がる → 11/5(雨がやんで1日目)は乾かす → 11/6 が作業日
   - 過去7日に雨が無ければ乾いているとみなす
5. 作業できる日のうち晴れは ◎(best)、曇りは ○(ok)

太陽熱消毒(`weather: "streak"`)は、作業できる日から3日以上晴れが続くときだけ勧める。

## 2. 地域区分(`zoneFromMeanTemp`)

過去3年の日平均気温の平均(年平均気温)で決める。設定で手動に変えられる。

| 年平均気温 | 区分 |
|---|---|
| 12℃ 未満 | 寒冷地 |
| 12℃ 以上 17℃ 未満 | 中間地 |
| 17℃ 以上 | 暖地 |

種袋の地域区分に合わせた目安。最近の気温上昇で東京などが暖地に入らないよう、中間地を広めに取っている。

## 3. 段取りの逆算(`planSteps` / `scheduleSteps`)

`data/crops.json` の `plans` にひな形がある。from/to は植え付け日からの日数。

| 手順 | 期間 | 前の手順からあける日数 |
|---|---|---|
| pH を測る | -28〜-15 | — |
| 苦土石灰 | -21〜-10 | 0(測った日にまいてよい) |
| 堆肥と元肥 | -10〜-5 | 7(石灰と同時に入れない) |
| 畝立て・マルチ | -6〜-1 | 1 |
| 植え付け | 0 | 予定日に固定 |

- `noLime: true` の作物(ジャガイモ・サツマイモ・ブルーベリー)は pH と石灰を飛ばす。
- 期間内で、前の手順から決まった日数以上あとの最初の作業日を割り当てる。
- 期間を過ぎた手順は「遅れ」として、今日から1週間以内の作業日に入れる。
- 期間が予報(16日)より先なら「未定」。

## 4. 画面

- 次の作業日: その日に割り当たった段取りは説明とリンクつき、季節の作業は名前だけ(下の「○月の土づくり」へのリンク)。
